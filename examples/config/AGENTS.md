# Personal instructions

Instructions for the agent that apply to all your projects, whichever
agent you use: language, tone, coding preferences, commit style...

roke adds them after its own instructions about the box (the container,
the services, the read-only .git), so you don't need to repeat those here.
For instructions meant for one agent only, use its own mechanism in
agents/<agent>/ (for example agents/claude/CLAUDE.md).
